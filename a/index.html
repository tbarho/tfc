Don't
  • Derive padding, gap, radius, or control height from φ.
  • Add a φ type scale.
  • Nest φ splits past one level.
  • Use φ in compact (IDE) density.
  • Add columns. Grid stays 12.

Do and don't

Do
  • Use the step job, not the hue: 400 border, 900 secondary text.
  • Reference primitives from semantic tokens. No raw hex below primitives.
  • Show a 2px ring plus 2px offset on every focusable element.
  • Match control heights 32 / 36 / 40 inside one row.
  • Name buttons with verb + noun. Sentence case.
  • Ship empty, loading, error, success for every pattern.
Don't
  • Signal state with color alone.
  • Use hue names in the semantic tier.
  • Animate past 300ms or ignore reduced motion.
  • Open menus on hover.
  • Add brand color in fundamentals. Skin owns it.
  • Invent a value a peer already publishes.
