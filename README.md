# The Final Countdown (tfc)

Public starting place for the design system guidance documents. Not a finished skill pack yet. The actual skill will be developed here with Ty.

## Layout

Core path is `guidance/`. Each document is a folder named `{order}-{purpose}` in all-kebab-case-lowercase. The number is build order (1 first).

| Path | Role |
| --- | --- |
| `guidance/01-principles-and-tokens/` | Foundations: audience, principles, tokens, imagery, a11y, states |
| `guidance/02-ui-components-and-blocks/` | Component and block contracts derived from 01 |
| `guidance/03-composition-gallery/` | Pages and flows composed only from 02 |

Dependency: 01 → 02 → 03. Brand changes expression, not coverage.

These HTML files are starting material only.
